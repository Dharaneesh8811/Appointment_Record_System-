Application Pages

Login

Users can sign in to access the appointment management system.

Book Appointment

Users can enter:

Full name
Email
Phone number
Appointment date
Reason

After submission, the appointment is stored in the MySQL database with PENDING status.

All Appointments

The appointment management page provides:

Appointment statistics
Search
Status filters
Appointment details
Status toggle
Delete functionality
Responsive Design

The interface is designed for:

Desktop
Tablet
Mobile

On desktop, the application uses a fixed sidebar navigation.

On mobile, the sidebar changes into a compact top navigation bar.

Error Handling

The application handles common errors such as:

Empty form fields
Failed API requests
Appointment not found
Invalid appointment status
Database connection errors
